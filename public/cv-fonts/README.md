# PDF typeface

The files come from the Google Fonts repository at commit
`39d11bc313031c9f68e21a297ce5e4a15cc5365e`, under `ofl/amiri`.
The font licence is in `OFL.txt`. The CV builder fetches these fonts on
Arabic PDF export only, from its own origin.
